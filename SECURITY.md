# Beveiliging

Heb je een beveiligingslek in Cogvivo gevonden? Meld het **privé** via het tabblad **Security → Report a vulnerability** van deze repository. Zet het nooit in een openbaar issue.

Beschrijf wat je vond en hoe het te herhalen is. Je krijgt zo snel mogelijk antwoord. Wie een lek netjes meldt, krijgt een vermelding op de bedankpagina, als je dat wilt.

*English: please report security issues privately via Security → Report a vulnerability, never in a public issue.*
