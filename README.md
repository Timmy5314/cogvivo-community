## What is Cogvivo?

A free social app where you **do** things instead of only watching them.

- **Challenges.** Film yourself doing a challenge and post it. Other players give your attempt 0 to 5 stars. Challenge a friend, or a random player, to a duel.
- **Monuments and places.** Visit a monument and add it to your collection. Add a place that is not on the map yet and it says *discovered by you*.
- **Countries.** Every country has its own badge and five lifelong challenges. Finish all five and it turns into a superbadge.
- **Everywhere.** Free on [cogvivo.com](https://cogvivo.com), installable as an app, in 12 languages.

## Help make Cogvivo

This repository is the public place to help. The source code of the app itself is private.

| What | How |
|---|---|
| 🌍 **Translate** | Improve your language or add a new one in [`translations/`](translations/). Start with an issue labelled [`good first issue`](https://github.com/Timmy5314/cogvivo-community/labels/good%20first%20issue). |
| 💡 **Ideas** | Suggest a challenge, a place or a feature in [Discussions](https://github.com/Timmy5314/cogvivo-community/discussions). |
| 🐞 **Bugs** | [Open an issue](https://github.com/Timmy5314/cogvivo-community/issues/new/choose). |
| 🔒 **Security** | Report it privately via [*Security → Report a vulnerability*](https://github.com/Timmy5314/cogvivo-community/security/advisories/new), never in a public issue. |
| 🧑‍💻 **Build along** | [Tell us what you would like to work on](https://github.com/Timmy5314/cogvivo-community/issues/new/choose). People who help actively can be invited to the private code. |

Read the [contribution terms](BIJDRAGEN.md) before you start. Everything in `translations/`, `challenges/` and `badges/` is updated automatically from the app.
