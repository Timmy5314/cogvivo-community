## Translating

1. Improve an existing file in [`translations/app/`](translations/app/) or [`translations/challenges/`](translations/challenges/), or copy `en.json` to `<code>.json` for a new language, for example `ko.json`.
2. Translate only the text on the right side of the colon. Keep the keys on the left and anything in `{curly braces}` exactly as it is.
3. Open a pull request titled "Translation: <language>". An automatic check makes sure everything fits.
4. After review, your translation goes into the app. Then it also appears here.
