# Security

Found a security problem in Cogvivo? Report it **privately** via the **Security → Report a vulnerability** tab of this repository, or email info@cogvivo.com. Never post it in a public issue.

Describe what you found and how to reproduce it. You will get an answer as soon as possible. If you report a problem responsibly, you can be thanked by name on Cogvivo's thank-you page if you want.
